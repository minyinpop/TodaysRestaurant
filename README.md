### 🌐｜版本資訊
- **此專案的版本為 6000.1.2f，請使用該版本的編輯器來製作。**
- **此專案採用 3D URP 渲染管線，請勿使用 BRP 或是 HDRP。**
---
### 🗂️｜使用插件
> **官方插件**
> 1. **2D Package**
> 2. **Cinemachine**
> 3. **New Input System**

> **額外插件**
> 1. **Dialogue System**
> 2. **Spine For Unity**
> 3. **Utage 4**
> 4. **RealToon**
> 5. **Rainbow Folders**

> [!IMPORTANT]
> **請先安裝好官方插件，額外插件已經附在 Assets 了。**
 ---
### 🔰｜安裝方式
- **請先把本地的 Unity Assets 資校夾給清空，過後直接把遠端的檔案給拉到本地的 Unity Assets 資料夾，這樣就完成追蹤與推送的環境了。**

> [!NOTE]
> **先把 Unity Assets 資料夾的檔案清空是因為要防止檔案衝突。**

> [!TIP]
> **有問題請洽 minyinpop@gmail.com，我將會在最快的時間內給予回覆。**

> [!IMPORTANT]
> **只需要在第一次清空 Unity Assets 資料夾即可，往後的變更不需要，除非換新的 Unity Assets 資料夾。**
